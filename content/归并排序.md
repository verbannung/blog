归并排序采用的是分治法的方式。其把大问题拆分成同构的小问题。
![[Pasted image 20260817220754.png]]

输入: 未排序的数组arr\[L]

# 理解

拆分问题:  二分的方式，把问题拆分成左半和右半 \[l,mid)，以及\[mid,r)，
递归拆分: 直到问题只有一个元素，该子问题天然排序
合并子问题: 合并排序好的左半和右半

![[Pasted image 20260817221456.png]]

二路归并非常像一颗二叉树，时间复杂度递推公式为
T(N) = 2T(N/2) + Θ(N)
其中 Θ(N)为归并的时间，由主定理得时间复杂度为O(NlogN)

# 代码
``` cpp
#include <_string.h>
#include <cassert>
#include <cstddef>
#include <cstring>

#include "types.hpp"
void merge(const ElementType* a,const ElementType* b,const std::size_t aLen,const size_t bLen,ElementType* result) {
    size_t i=0,j=0,k=0;

    while(i<aLen&&j<bLen) {
        if(a[i]<b[j]) {
            result[k++]=a[i++];
        }else {
            result[k++]=b[j++];
        }
    }
    while(i<aLen) {
        result[k++]=a[i++];
    }
    while(j<bLen) {
        result[k++]=b[j++];
    }

}

void mergeSort(ElementType* arr,int l,int r) {
    if(r-l<=1) //显然只有一个元素的时候当然是有序的 
        return;
    auto mid=l+((r-l)>>1);
    mergeSort(arr,l,mid);
    mergeSort(arr,  mid,  r);
    ElementType* temp = new ElementType[r-l];
    merge(arr+l,arr+mid,mid-l,r-mid,temp);
    std::memcpy(arr + l, temp, sizeof(ElementType) * (r - l));
    delete [] temp;
}
```
