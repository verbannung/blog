# Footer (local fork)

Fork of [`quartz-community/footer`](https://github.com/quartz-community/footer) for this site.

Shows a personal contact email instead of the default "Created with Quartz" attribution.

## Options

```yaml
- source: ./plugins/footer
  enabled: true
  options:
    email: verbannung@yeah.net
    links:
      GitHub: https://github.com/verbannung/blog
```
